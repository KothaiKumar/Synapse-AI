
# SynapseAI

## Bio-Visual Multimodal Brain Tumor Classification

SynapseAI is a research-oriented application for brain tumor classification using MRI images and a risk-gated multimodal learning framework.

## Features

- MRI image upload and analysis
- Brain tumor classification
- Risk-gated multimodal fusion architecture
- Genomic feature processing
- Grad-CAM-based visual explanations
- Interactive application interface

## Model Architecture

The framework includes:
- MobileNetV2-based MRI encoder
- Genomic feature encoder
- Risk estimation head
- Risk-gated fusion module
- Classification head
- Bio-Visual Grad-CAM

## Technologies Used

- Python
- PyTorch
- TorchVision
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SynapseAI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the application using:

```bash
streamlit run app.py
```

Replace `app.py` with the actual application entry-point filename if different.
